\doxysubsection{DescriÃ§Ã£o detalhada}
Define a interface de operações de negócio sobre projetos. 

Permite que a camada de apresentação realize operações de criação, listagem, consulta, edição e exclusão de projetos, além do gerenciamento de participantes vinculados a cada projeto, sem depender da implementação concreta.
