Representa e valida um código de identificação alfanumérico com formato fixo. 

Esta classe encapsula uma string que deve seguir um padrão estrito de formatação: ter exatamente 6 caracteres, onde os 3 primeiros são letras e os 3 últimos são dígitos. Cada entidade (pessoa, projeto, quadro, cartão de atividade) possui um identificador único.
